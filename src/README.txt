Déesse UI Replay Linker Extension

This resource-pack extension adds the Replay button/link to Déesse UI. It is
an integration layer only and does not contain replay functionality.

SUPPORTED NATIVE REPLAY MODS

- BedrockReplay by light: intended for LeviLaunchroid.
  Support: https://discord.gg/BbM6xZNKfq
- Playback by wo55555: native LeviLamina client mod.
  Project: https://github.com/wo55555/Playback

IMPORTANT

This pack will not provide replay functionality by itself. A compatible
native replay mod is required. BedrockReplay requires its supported
LeviLaunchroid environment; Playback requires LeviLamina in a compatible
LeviLaunchroid setup.

This extension only changes the Déesse UI integration and does not bundle or
replace Déesse UI, BedrockReplay, Playback, LeviLaunchroid, or LeviLamina.

Target checked source: Déesse UI v1.3.9 (MCBE 26.40+).
